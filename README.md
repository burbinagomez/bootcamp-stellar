## Requisitos

- Node.js 22.18 o superior
- npm 10 o superior

## Instalación

```bash
git clone https://github.com/burbinagomez/bootcamp-stellar.git
cd bootcamp-stellar/frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre http://localhost:3000 en el navegador.

Versión desplegada: https://origen-two-sigma.vercel.app
